# React-чат для MAX / MAX React Chat

## Онлайн-демо / Live demo

[Открыть демо](https://max-chat-ira-demo.wakingbun2.chatgpt.site)

Нажмите «Попробовать демо»: вымышленные чаты и автоматические ответы без GREEN-API. Сообщения никуда не отправляются.


Тестовое задание: отправка и получение текстовых сообщений
в MAX через GREEN-API.

## Возможности

- Ввод ID инстанса и API токена.
- Проверка состояния подключения.
- Создание и выбор чатов по номеру телефона.
- Отправка текстовых сообщений кнопкой или по Enter.
- Получение входящих текстовых сообщений вручную
  и автоматически.
- Разделение переписки по ID чата.
- Проверка пустых значений и обработка ошибок запросов.
- Адаптивный интерфейс.

## Технологии

React, JavaScript, Vite, CSS, GREEN-API.

## Запуск

Проект разработан с Node.js 24.16.0 и npm 11.13.0.

Установите зависимости:

```bash
npm ci
```

Запустите приложение:

```bash
npm run dev
```

Откройте адрес, указанный в терминале.

## Подключение GREEN-API

1. Создайте инстанс MAX в кабинете GREEN-API.
2. Авторизуйте его через QR-код в приложении MAX.
3. Включите уведомления о входящих сообщениях и файлах.
4. Оставьте URL отправки уведомлений пустым:
   приложение получает их через HTTP API.
5. Введите idInstance и apiTokenInstance в интерфейсе.
6. Нажмите «Подключиться».

В текущей версии адрес API:
https://3100.api.green-api.com

Если у вашего инстанса другой apiUrl, измените константу
apiUrl в src/App.jsx на значение из личного кабинета.

## Проверка обмена сообщениями

1. Введите номер получателя с кодом страны,
   без плюса, пробелов и скобок.
   Создание чата поддерживает номера РФ и Беларуси.
2. Нажмите «Создать чат».
3. Отправьте текстовое сообщение.
4. Включите автоматическое получение.
5. Ответьте с аккаунта получателя в MAX.
6. Убедитесь, что ответ появился в выбранном чате.

Для проверки разделения переписки создайте второй чат
и переключайтесь между собеседниками.

## Используемые методы API

- getStateInstance — проверка подключения.
- checkAccount — получение ID чата по номеру.
- sendMessage — отправка текста.
- receiveNotification — получение уведомления.
- deleteNotification — подтверждение обработки уведомления.

## Ограничения

- После успешного подключения чаты и сообщения сохраняются в localStorage этого браузера. Для восстановления после обновления нужно снова подключиться к тому же инстансу. ID и токен не сохраняются; ключ истории содержит SHA-256 от ID инстанса. Демопереписка сохраняется отдельно от настоящих чатов.
- Локальная история не зашифрована и доступна пользователю этого профиля браузера. Если браузер запрещает localStorage или его место закончилось, история остаётся только в памяти.
- История из MAX не загружается.
- Отображаются входящие уведомления типа textMessage.
  Другие типы уведомлений обрабатываются без отображения.
- Успешный ответ sendMessage означает принятие запроса API,
  но не подтверждает доставку получателю.
- При ошибке автоматическое получение останавливается.
- При остановке текущий запрос завершается,
  новые запросы не запускаются.

## Данные доступа

Токен вводится в интерфейсе и хранится в памяти приложения.
Не добавляйте настоящий токен в исходный код или репозиторий.
## Деморежим

Нажмите «Попробовать демо», чтобы открыть два вымышленных чата без ID и токена. Можно переключать чаты и отправлять текст: приложение добавит автоматический демонстрационный ответ. Запросы к GREEN-API в этом режиме не выполняются.

Кнопка «Подключить GREEN-API» возвращает настоящий режим и скрывает демонстрационную переписку. Переключение доступно после завершения текущих операций; автоматическое получение нужно сначала остановить. Данные демо и выбранный деморежим восстанавливаются после обновления страницы.

## Удобство переписки

- Имя выбранного чата можно изменить в заголовке; пустое имя возвращает отображение номера.
- В списке показаны последнее сообщение и число непрочитанных входящих. Открытие чата отмечает его сообщения прочитанными локально; это не отправляет подтверждение прочтения в MAX.
- Исходящие сообщения получают статусы «Отправляется», «Принято API» или «Нет подтверждения». Принятие API не означает доставку. Автоматической повторной отправки нет.
- При восстановлении страницы незавершённая отправка показывается как неподтверждённая.
- На экранах до 700 px список чатов и переписка открываются отдельно, возврат — кнопкой «← Чаты».
